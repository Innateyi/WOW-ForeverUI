【无限服】EllesmereUI + kkowoUI 现代简洁整合界面 - 全职业通用 - 装好即用

专为《魔兽世界：无限》打造的现代简洁整合方案：深色半透明玻璃质感、默认跟随职业主题配色，兼顾信息完整与视野清爽。核心体验由原创模块化插件 kkowoUI（23 个可单独开关模块，轻量无冲突）驱动，其余主流插件全部保留原版，后续可直接在管理端内正常更新。安装后进游戏即同步作者同款布局，全职业装好即用。

【一、核心功能一览】

1. 视觉与界面统一
- 全局现代扁平：头像、动作条、姓名板、团队框、小地图、背包风格统一，默认随当前角色职业自动匹配主题配色。
- 鼠标提示优化：联动 PrettyTooltip 紧凑卡片，装备、技能、NPC 信息清晰不挡屏，已关闭 Alt 误切原版并优化字号比例。
- 面板与飘字美化：角色声望、技能、PvP 面板重绘，高清宠物快乐度，资源与施法条风格统一；伤害数字默认醒目标题字体（可切换其他字体或原版），支持自身受击与经验飘字分级。
- 细节防遮挡：无限服世界刷新顶部提示框美化下移不遮挡经验条；职业与宠物训练师自动隐藏已学会和暂不可学技能；宏界面放大、好友列表加高。

2. 沉浸探索与智能稳帧
- 沉浸探索淡隐：非战斗、无目标且生命与法力充足时自动柔淡副动作条、任务栏、系统栏与伤害统计；进战、选目标、施法或鼠标移上瞬间清晰（副本内自动关闭）。
- 场景自动稳帧：主城人多或大型团本自动切换省资源画面档位，离开自动还原；主城自动隐藏友方玩家名与公会头衔，明显减轻卡顿。
- 副本过滤闲聊：副本战斗中自动过滤综合与公共频道闲聊消息（不影响小队、团队、公会与密语）。

3. 聊天与社交
- 左侧融合竖栏：世、综、交、团、掷点、喊、会、密、队、说 一键切换，实时高亮当前输入框并记住上次频道；按住 Alt 点击频道可自定义排序。
- 快捷世界频道：右键「世」一键加入或离开常用世界频道（无需额外插件，频道名可在设置或命令里自定义）。
- 实用按钮收纳：复制聊天、聊天设置（右键直达设置面板）、翻看历史后的回底高亮提示均在同一条栏里，支持公屏指定词提醒与密语提示音。
- 右键菜单与邮箱：右键玩家一键复制「名字-服务器」与公会邀请；寄信时右侧自动列出本服小号与收藏联系人（右键可移除），发件箱收件人、主题与邮资排版对齐。
- 趣味职业表情喊话：按职业内置趣味文案，组队时坐下喝水自动带上法力百分比，复活、拉人、开门、灵魂石与招牌技能也有专属文案；副本内发橙色表情，野外组队发到队伍频道，单人不发送，带防刷屏冷却，可自定义文案或用 /kk emote 宏一键发送（不需要可在设置里关闭）。

4. 任务升级与地图采集
- 智能任务助手：默认开启自动交任务（多选装备奖励自动保护防误选），按住 Shift 临时暂停；任务追踪标题栏嵌入「接、交、通告、本图」快捷钮，一键切换自动接任务或仅看本图任务。
- 等级与经验追踪：任务标题前显示难度着色等级，右侧对齐预计经验（任务道具自动左移不重叠）；顶部融合经验条集成职业徽印、等级、装等、可交任务预览、双倍与预计升级时间。
- 顺滑练级导航：搭配 Polestar 完整中文练级指南、Waypoint UI 世界 3D 导航箭头、Vamoose 一键最快交通路线（炉石、飞点、船艇、传送门）。
- 大地图与采集提醒：大地图标注各区域等级区间；小地图 NPC 图标自动去重（以 Polestar 为准不与 Questie 重复）；草药、矿点、任务物件、钓鱼浮漂头顶图标提醒并保活拾取闪光。

5. 拾取、背包与分配条
- 极速静默拾取：右键快速拾取不闪窗，仅包满或需要确认的物品才弹框，空包裹不闪框并在拾取信息处提示；配合屏幕侧边现代拾取微播报，物品、金币、经验、声望自动合并，非战斗悬停可看装备属性。
- 背包清理助手：商人处自动卖灰、自动修理；背包满时列出最不值钱的物品（联动 Auctionator 拍卖行估价防误卖）。
- 现代装备分配条：扁平风格带倒计时条，需求、贪婪、分解、放弃一键操作。

6. 战斗、副本与系统栏
- 战斗提示与预警：进战与离战柔和图标动效、BigWigs 无限服首领预警、危险站位声音提示、法术触发高亮、EUI 冷却管理器职业预设冷却条（图标 + 技能名 + 倒计时，冷却中才显示，学会新技能自动补上）。
- 核心属性与耐久：全职业自动匹配关键属性，与装备耐久融合成透明清爽面板，悬停查看全身各部位耐久明细与预计修理费。
- 扁平矢量标记条：重绘 8 枚团队标记，加清除、就位确认、开怪倒数一键完成，同步替换头像与姓名板标记。
- 一体化系统栏：底部高清矢量微菜单、一键炉石冷却、时钟与帧率延迟（悬停看内存排行，点击释放内存）、天赋与传承未分配点数提醒，右键系统菜单直达设置面板。
- 猎人专属音效：远程输出与陷阱类技能自定义音效，自动识别不同类型远程装备切换两套音效（默认仅猎人生效，支持单技能开关）。
- 术士灵魂石提醒：给队友或自己使用灵魂石后显示小巧倒计时卡片，快到时间时变色提醒，可选中文语音提醒及时补上（默认仅术士角色生效）。

【三、使用说明与常用命令】

- 安装即用：安装后直接进游戏即可，所有角色自动应用同一套布局；分享配置已清理个人数据，不含任何个人角色、好友、金币账本或聊天记录。
- 按需定制：kkowoUI 的 23 个模块均可单独开关，检测到同类插件会自动让位不冲突。
- 备份建议：如日后想换回原配置，应用本分享前建议先备份游戏目录下的配置文件夹。

常用游戏内命令：
- /kk：打开 kkowoUI 设置面板（也可右键底部系统菜单图标直达）
- /kk unlock：开启或关闭界面解锁拖动模式
- /kk status：查看全部模块实时启用与自动让位状态
- /kk world 频道名：修改「世」按钮右键加入的世界频道（加 reset 恢复默认）
- /kk kw 词1,词2：开启公屏指定词提醒（加 clear 清空关闭）
- /kk hud：手动切换沉浸探索自动淡隐
- /kk boost：手动锁定或解除稳帧档位
- /kk city：快速切换友方玩家名字显示模式
- /kk ss：预览灵魂石提醒卡片（/kk ss voice 试听语音）
- /kk emote preview：本地预览趣味表情效果（/kk emote 1 发送自定义快捷宏 1）
